## Contributor Recognition Policy

A contribution may be recognized in one or more of the following ways:

- software authorship in `CITATION.cff`;
- acknowledgement in this file;
- release notes;
- Git commit history; or
- acknowledgement in a related scientific publication.

Software authorship should reflect substantial intellectual or technical
contributions and should be agreed by the maintainers and relevant
rightsholders. Small corrections, issue reports, and minor documentation edits
may be acknowledged without creating software authorship.

## Updating This File

When adding a contributor:

1. use the contributor's preferred full name;
2. obtain permission before publishing personal contact information;
3. use a verified ORCID when available;
4. describe the contribution specifically; and
5. update `CITATION.cff` when the contributor should be included in the formal
   software citation.
